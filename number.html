Number

Number Data Types:

Byte:
1 byte (8 bits) - Stores values from 0 to 255
Integer:
2 bytes (16 bits) - Stores values from -32,768 to 32,767
Long Integer:
4 bytes (32 bits) - Stores values from -2,147,483,648 to 2,147,483,647
Single:
4 bytes (32 bits) - Stores values from -3.402823e+38 to -1.401298e-45 and 1.401298e-45 to 3.402823e+38 (~7 decimal digits precision)
Double:
8 bytes (64 bits) - Stores values from -1.7976931348623157e+308 to -4.9406564584124654e-324 and 4.9406564584124654e-324 to 1.7976931348623157e+308 (~15 decimal digits precision)
Decimal:
12 bytes (128 bits) - Stores values with up to 28 significant digits (High precision decimal type)
Scientific Form: 0
